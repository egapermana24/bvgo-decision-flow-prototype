# BVGO Decision Flow Prototype

Standalone static concept for a notification-to-decision flow. Open `index.html` in a browser or serve the directory with any static web server.

The prototype uses selected public BigRR Action titles and images as visual references. Deadlines, classification, decision prompts, responses, and notification behavior are illustrative only. No operational API calls or real push notifications are made.

Core scenarios: urgent inspection, bad review, and informational update. The app interface separates pending owner decisions from updates, supports property filtering/search, opens a notification into the specific Action, and keeps a decision control visible on the detail view.
